# FatMan

An accurate 3D model of the first implosion/plutonium/fission weapon.

## Documentation

This repo includes documentation collected in the process of creating this model.

## 3D Model

The model consists of three major components: the physics package (which includes all of the explosives and fissionable material inside of an spherical aluminum shell), the support functions (including the fireset, the radar, the timer, the barometric sensors, and associated cabling), and the ballistic shell (consisting of the outer casing, tail section, radar antennae, and safeing/arming plugs).

## Tools for Generating the Model

While Fusion360 is the primary tool used to create this model, several other tools were used in order to create the explosive lenses.

### Workflow for Creating Explosive Lenses

* Python explLenses.py
  - this tool generates the Cartesian Oval that describes the interface between the fast and slow explosive lenses
  - it generates the points that define a closed polygon for the profiles of the hexagonal and pentagonal slow explosive lens
    * it writes the points out to files in both OpenSCAD and Python formats -- in './slowLensPts.scad' and './slowLensPts.py', respectively
* Python slowLens.py
  - this generates CGS files for the pentagonal and hexagonal slow explosive lenses
    * it reads in the slow lens profile points from the files generated by 'explLenses.py'
    * it spins the profiles around the z-axis to generate a solid, and then it clips it against the outer diameter of the boosters' felt pad
  - it writes the pentagonal and hexagonal solid geometry to the files './scad/pentSlowLens.scad' and './scad/hexSlowLens.scad', respectively
* OpenSCAD explLenses.scad
  - this OpenSCAD code is used to generate four types of explosive lenses solids for both the hexagonal and pentagonal explosive lenses
  - each of the generated lens components are written to files in CSG format for use with FreeCAD
  - this code reads in the CSG files containing the raw (i.e., untrimmed) slow lens objects generated by 'slowLens.py'
    * it trims the slow lenses by intersecting them with their associated (hexagonal or pentagonal) prisms
    * it can generate object in their representative positions (e.g., vertical), and it can also rotates the lenses to place them in their approapriate positions
  - the different types of explosive lenses that can be generated by this code, for both hexagonal and pentagonal types of prisms are (along with their associated files):
    * Booster Component: './csg/{hex,pent}Booster.csg'
    * Slow Lens Component: './csg/{hex,pent}SlowLens.csg'
    * Fast Lens Component: './csg/{hex,pent}FastLens.csg'
    * Composite Slow and Fast Lens: './csg/{hex,pent}Lens.csg'
  - in addition to generating individual components (in representative positions), this code can also be used to generate different sets of lens components, e.g.:
   * all of the Boosters: './csg/boosters.csg'
   * all of the Slow Lenses: './csg/slowLenses.csg'
   * all of the Fast Lenses: './csg/fastLenses.csg'
   * all of the hexagonal and pentagonal Slow Lenses: './csg/{hex,pent}SlowLenses.csg'
   * all of the Composite Slow and Fast Lenses: './csg/lenses.csg'
  - using OpenSCAD it is possible to write out the desired objects in CSG format for conversion into STEP format files by FreeCAD
* FreeCAD './csg/*.csg'
  - open the desired CSG files export each shape into STEP format files
  - select the last entry in the device tree on the left
  - export to STEP format from 'File->Export'
* Fusion360
  - open each STEP file with Fusion360 and save in the FatMan folder
  - do all the trimming of the spherical features here as it works much better with solids
